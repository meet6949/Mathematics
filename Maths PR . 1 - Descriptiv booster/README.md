# 📊 Income Distribution & Household Demographics Analysis

## 📌 Objective

This project analyzes household income data using statistical methods and visualizations.

## 📂 Dataset

* 200 records (synthetic data)
* Columns:

  * Age
  * Income
  * Education Level
  * Family Size
  * Owns House
  * Urban/Rural

## 🧠 Concepts Used

* Mean, Median, Mode
* Variance & Standard Deviation
* Skewness & Kurtosis
* Histogram & Boxplot

## 📊 Key Insights

* Income distribution is slightly right-skewed
* Presence of high-income outliers
* Unequal income distribution across households

## 🛠 Tools Used

* Python (Pandas, NumPy, Matplotlib)

## 📈 Visualizations

* Histogram of Income
* Boxplot for Income Spread

## 🚀 Conclusion

Statistical analysis helps understand income inequality and demographic patterns effectively.
